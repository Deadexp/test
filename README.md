# Мой первый проект

Учебный сайт для знакомства с кодом, GitHub и Codex. Обычные HTML и CSS: установка библиотек, ключи API и база данных не нужны.

## Что находится в репозитории

- `index.html` — текст и структура страницы.
- `styles.css` — цвета, шрифты и расположение элементов.
- `README.md` — эта инструкция, которую GitHub показывает на странице репозитория.

## Как посмотреть сайт на своём компьютере

Скачайте файлы репозитория и откройте `index.html` в браузере.

Если установлен Python 3, можно запустить локальный сервер из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте в браузере локальный адрес сервера на порту 8000. Для остановки нажмите `Ctrl+C` в терминале.

В облачной среде Codex эта команда нужна для внутренней проверки сайта. Публикация файлов на GitHub сама по себе не размещает сайт в интернете; для этого можно отдельно настроить GitHub Pages.

## Как учиться с Codex

Начните с небольшой задачи, например:

> Измени заголовок сайта на «Мои идеи» и сделай кнопку фиолетовой.

Codex изменит файлы. Посмотрите изменения и попросите объяснить непонятные строки. Затем можно попросить:

> Сохрани изменения коммитом и отправь их на GitHub.

**Репозиторий** — папка проекта с историей изменений. **Коммит** — сохранённый шаг в этой истории. **Ветка** — отдельная линия работы; основная ветка этого проекта называется `main`. **Push** — отправка коммитов на GitHub.

## Проверка в облачной среде

Из `/workspace/test` запустите сервер командой выше. В другом терминале проверьте ответы:

```sh
curl --fail http://127.0.0.1:8000/
curl --fail http://127.0.0.1:8000/styles.css
```

Оба запроса должны успешно вернуть содержимое файлов. Автоматических тестов и этапа сборки в этом небольшом проекте пока нет.
